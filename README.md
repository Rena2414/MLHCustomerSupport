# Classly

An online learning platform with roles Admin, Teacher, Student and Parent, and an AI support bot for students built for MLH.

- Students ask how to use the platform, cancel their subscription, and report concerns about a teacher.
- Admins see per-teacher concern analytics with an AI summary.

Start here: `docs/ARCHITECTURE.md` (architecture, API, seed logins, how to run) and `CLAUDE.md` (engineering rules).
